# Dietary Guidance RAG Chatbot — API Specifications

This document extracts and formalizes the API contracts defined in the architecture for Milestone 2. 

---

## 1. POST `/api/chat`

Handles the core conversational RAG flow. It receives the user's message, processes it through the scope guard, router, retrieval, generation, and verification pipelines, and returns a fully hydrated response.

### Request Body

```typescript
{
  "userMessage": string;       // The user's input query
  "conversationId": string;    // CUID linking to the existing conversation history
  "documentFilter"?: string[]; // Optional array of doc_ids (e.g., ["D4", "D5"]) to force single/per-document retrieval
}
```

### Response Body (`NutritionResponse` v2)

```typescript
{
  "status": "answered" | "not_covered" | "out_of_scope";
  
  // The conversational reply generated by the LLM (or a template refusal)
  "answer_text": string;
  
  // The list of validated, grounded claims. Empty if status != "answered"
  "claims": ClaimV2[];
  
  // Optional list of conflicting viewpoints detected across multiple authorities
  "disagreements"?: Disagreement[];
  
  // Populated when status = "not_covered". Tells the user which documents were searched.
  "searched_documents"?: string[];
}
```

### Types

#### `ClaimV2`
```typescript
{
  "claim_text": string; // Standalone, faithful statement ≤ 30 words
  "citation": Citation;
}
```

#### `Citation`
Hydrated by the server from the `Document` and `Chunk` databases.
```typescript
{
  "chunk_id": string;
  "doc_id": string;
  "document_title": string;
  "publisher": string;
  "year": number;
  "url": string; // Includes #page=N hash for PDF linking
  "section": string;
  "legal_status": string;
  "quote": string; // Verbatim substring from the chunk text
}
```

#### `Disagreement`
```typescript
{
  "topic": string;
  "positions": {
    "doc_id": string;
    "publisher": string;
    "year": number;
    "statement": string;
    "citation": Citation;
  }[];
}
```

## 2. GET `/api/documents` (New)

Returns the metadata list of all available corpus documents. Used by the frontend to populate the `documentFilter` dropdown menu.

### Response Body

```typescript
{
  "documents": {
    "doc_id": string;
    "title": string;
    "publisherShort": string;
    "year": number;
  }[]
}
```

---

## 3. GET `/api/chunks/[chunkId]` (New)

Fetches the raw, full text of a specific chunk. Used by the `SourcesPanel.tsx` in the frontend when a user clicks on a claim marker to see the broader context around the highlighted quote.

### Request Params
- `chunkId` (string in URL path)

### Response Body

```typescript
{
  "chunk_id": string;
  "text": string;
  "section_heading": string;
  "population": string[];
}
```
